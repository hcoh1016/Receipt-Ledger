## 문서 간 조정 사항

- 사용처: 데이터 규칙에 따라 선택 입력으로 구현. UI 자료의 필수 표시는 수정 필요.
- 조회 성능: 요구사항 PDF NFR-03은 5초, 테스트/UI 자료는 2초. 데이터 코드에서 임의 대기하지 않으며, 2초를 개발 목표로 두되 최종 합격 기준은 팀 문서에서 통일해야 함.
- 테스트 도구: 기존 조사 보고서는 Jest/Detox 제안. 현재 자동 테스트는 Node.js Test Runner + tsx + SQLite를 사용. Detox E2E 테스트는 최종 UI 연동 후 작성 예정이며, 도구 조사 보고서도 실제 구성에 맞게 갱신 필요.

## 파서의 한계

영수증 서식마다 라벨/열 배치가 다릅니다. 총액은 합계/결제금액 등 명확한 라벨 후보만 사용하며 다른 후보와 충돌하면 null입니다. 사용처는 상호명 라벨 또는 상단 짧은 문자열 후보를 제안합니다. 품목은 '품목명 수량 행금액' 패턴만 지원합니다. 인식 확률을 계산하지 않으며 모든 핵심 필드를 검토 대상으로 전달합니다. 사진 30장에 대한 정확도 목표 달성은 아직 확인하지 않았습니다.
