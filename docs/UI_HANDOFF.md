# ReceiptLedger UI 인계

기존 `LedgerProvider`와 데이터/OCR 서비스를 유지하고 연결 확인 화면을 실제 사용 화면으로 교체했습니다. 원본 폴더 대신 작업 복사본에서 구현했습니다.

## 실행

프로젝트 루트(package.json이 있는 폴더)를 VS Code에서 열고 실행합니다.

```powershell
npm ci
npm run typecheck
npm test
npm run android
```

Node 24, JDK 17, Android SDK와 실행 중인 에뮬레이터 또는 USB 디버깅 기기가 필요합니다. Expo Go는 커스텀 한국어 OCR 모듈을 지원하지 않습니다. 기존 package.json 및 lockfile의 버전을 유지했으며 새 의존성은 추가하지 않았습니다.

## 연결 및 화면 동작

- 새 폼마다 고정 request key를 사용하고 연속 탭을 차단합니다. 수정은 update를 사용합니다.
- 저장 성공 후 저장한 결제월의 목록으로 이동하여 조회하고, 탭 이동 시 통계를 재조회합니다.
- 목록은 기간과 카테고리 조건을 적용하고, CSV는 같은 적용된 조건을 사용합니다. 입력만 바꾼 필터는 적용 버튼을 누르기 전까지 반영되지 않습니다.
- 사용처/메모는 선택, 결제일/총액은 필수입니다. 설계서의 사용처 필수 문구보다 백엔드 계약 및 테스트 문서의 선택 입력 규칙을 따릅니다.
- 분석 완료는 저장이 아닙니다. 결측값을 그대로 표시하고 사용자 확인 후 저장합니다.
- 실제 진행률 API가 없어 가짜 백분율 대신 로딩과 경과 시간을 표시합니다. 30초 제한은 기존 서비스에서 수행합니다.
- 분석 취소/화면 종료 때 AbortSignal로 늦은 결과를 차단합니다. 앱 피커 캐시만 정리하며 갤러리 원본은 삭제하지 않습니다.
- Android 시스템 사진 선택기를 사용하므로 전체 사진 접근 권한을 선제 요청하지 않습니다. 카메라 권한 거부 시 설정·사진 선택·직접 입력 경로가 있습니다.
- 공유 화면 종료는 전송 성공으로 표시하지 않으며 원본 내역을 유지합니다.

## 검증 결과 및 남은 확인

- 기존 데이터/OCR 서비스 테스트 21개 + 신규 폼 테스트 5개 = 26개 통과. 패키지 설치가 차단되어 Node 24 내장 TypeScript 변환 로더로 같은 테스트 파일을 실행했습니다.
- TypeScript 컴파일러의 transpileModule로 TS/TSX 38개 파일 구문 검사 통과. 이는 전체 의미 타입 검사가 아닙니다.
- npm ci는 현재 실행 환경에서 실패했습니다. 전체 npm run typecheck, Android 빌드, UI 실기기 검증, Maestro E2E는 미실시입니다.
- 촬영은 시스템 카메라를 사용합니다. 설계서의 앱 내부 카메라 가이드 오버레이·실시간 흐림/반사 감지는 구현하지 않았습니다. 사진 확인에서 수동 품질 안내를 제공합니다.
- 내역은 기간/카테고리 조회를 지원하며 사용처 텍스트 검색은 아직 없습니다.
- 360dp 세로·키보드·큰 글꼴·Android 제스처/3버튼 내비게이션에서 잘림과 여백을 기기에서 확인해야 합니다. 시스템 바 여백은 기본값을 적용했으며 실제 기기 검증이 필요합니다.
- 실제 한국어 OCR 정확도/오프라인/성능, 저장 공간 부족, OS 권한 거부 및 CSV 공유 앱의 결과는 기기 시험 대상입니다.

## 기기에서 확인할 순서

1. 빈 상태 → 지출 등록 → 직접 입력. 사용처 없이 날짜와 8,000원 저장. 목록 1건, 월 합계 8,000원 확인.
2. 총액 0/음수/소수/상한 초과, 잘못된 날짜를 입력하여 필드 오류 확인.
3. 상세 수정·삭제 후 목록과 통계 갱신 확인. 삭제 취소 시 보존 확인.
4. 기간/카테고리 조건 적용 → 같은 조건의 CSV 행/합계 확인. 0건은 헤더만 생성 확인.
5. 촬영/사진 선택 취소·권한 거부·분석 실패·30초 초과·분석 중 뒤로가기·재시도 확인.
6. 실제 영수증의 추출값·품목 수정 후 저장, 앱 재시작 후 데이터 유지 확인.

Maestro 설치 환경에서 `maestro test e2e/manual-entry.yaml`로 초안 시나리오를 실행할 수 있습니다. 기존 데이터가 있으면 결과에 영향을 줄 수 있으므로 별도 테스트 기기를 사용합니다. 실행 및 통과를 보증하는 결과 파일이 아닙니다.
